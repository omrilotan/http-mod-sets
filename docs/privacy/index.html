Privacy Policy

Last updated: October 29, 2026

HTTP Mod Sets is a browser extension that modifies HTTP requests and responses using rules you create. This policy explains what it does with data. In short: it collects nothing.

Data we collect

None. The extension has no analytics, telemetry, crash reporting, advertising, accounts or sign-in. We run no servers, and the extension's own code makes no network requests.

Data stored on your device

The rules you create (sets and mods) are stored in your browser with chrome.storage.local. They stay on your device. They are not synced to your Google account, and they are never sent to us or anyone else. Uninstalling the extension deletes them.

The popup also remembers which sets you folded, in the extension's local storage. This never leaves your device either.

How the extension uses its permissions

  • storage: saves your rules on your device.
  • tabs: reads the current tab's address to show which of your rules match it, to count them on the toolbar icon, and to suggest a rule for the current site. The address is not stored or sent anywhere.
  • declarativeNetRequest: applies your header and blocking rules inside the browser.
  • Access to all sites: your rules can target any site you choose. A script on each page applies your body-editing rules to that page's fetch() requests. It reads the page's address and the list of resources it loaded only to show you which rules match. Nothing is recorded or transmitted.

Requests you modify

When a rule edits a request, the edited request goes only to the site it was already addressed to, exactly as your browser would send it without the extension. The extension does not copy, log or redirect your traffic.

Import and export

Exporting saves your rules to a file on your computer. Importing reads a file you choose. Neither step involves any server.

Third parties

None. The extension shares no data with third parties, because it has none to share.

Children

The extension collects no personal information from anyone, including children.

Changes

If this policy changes, the new version will be published on this page with a new date. The source code is public, so every change to the extension can be reviewed.
