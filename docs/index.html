How it works

one popup · no setup
  1. Make a setPress N. It starts with the site you're on.
  2. Add modsHeaders, bodies or blocking. Mods run top to bottom.
  3. Edit in placeClick a mod to change it. Drag to reorder.
  4. Switch itTurn a set or a single mod on and off. A green dot shows what matches the page.

What it does

6 features · 0 trackers
  • 01HeadersAdd or change request and response headers.
  • 02BodiesRewrite request and response bodies, with regex and $1 captures.
  • 03BlockingBlock any matching request.
  • 04SetsGroup mods by URL and method. Switch a set or a single mod on and off.
  • 05At a glanceSee which sets match the page, in the popup and on the toolbar badge.
  • 06PortableImport and export your rules as JSON.

We collect
nothing.

Your rules stay in your browser. Edited requests go only where they were already going. The code is public, so you can check.
